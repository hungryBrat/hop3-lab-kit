1. BRING

[ ] Fiducial sheet printed at 100%, 3+ copies. Ruler-check the 100 mm
    bar: measured = ________ mm
[ ] Blue/black felt-tip pen (NO red)  [ ] Tape  [ ] Steel ruler + measuring tape

2. SETUP (lab laptop, at minute 0)
[ ] bash setup.sh   (venv + ftservo-python-sdk)   [ ] mkdir -p photos video session
[ ] Plug in; lsusb ; dmesg | tail ; ls /dev/ttyACM* /dev/ttyUSB*
[ ] No port but lsusb shows 1a86:7523 -> brltty mask:
      sudo systemctl mask brltty-udev.service brltty.service
      sudo systemctl stop brltty-udev brltty ; replug
[ ] Permission denied -> groups lists dialout? else (last resort)
      sudo chmod a+rw /dev/ttyACM0   (or /dev/ttyUSB0)
[ ] PSU voltage label: ______ V (12 V vs 7.4 V) -> write in session/notes
[ ] Pings fail: PSU on? jumper on A? daisy-chain cable? baud 1M? ESP32 board?
[ ] NO MATLAB on lab laptop: raise paper with books so its height above the BASE BOTTOM
    is 40, 60, 80, 100 or 120 mm (ruler!) and use data/cmd_primary_z<that>.csv.
    Pen tip pressed ~2 mm: set the stack ~2 mm higher than the file z.

[ ] Touch-off: $P $C/touchoff.py  -> HOLD THE ARM (torque off). 4 fiducials F1-F4,
